# HEAL — índice de handoffs

Cada agente tem um handoff próprio com estado real, arquivos, evidência, erros e próximo owner. Quando horário ou comando não foi capturado no retorno original, o registro diz explicitamente `não capturado`; nenhum dado foi reconstruído por suposição.

| Agente | Task | Handoff |
|---|---|---|
| HEAL-00 | integração | `HEAL-00.md` |
| HEAL-01…HEAL-22 | T001…T022 | arquivo de mesmo ID nesta pasta |
| HEAL-social | asset social | `HEAL-social.md` |

Os artefatos especializados continuam sendo a evidência principal. Estes arquivos são o envelope operacional de entrega, não uma duplicação integral da pesquisa.
